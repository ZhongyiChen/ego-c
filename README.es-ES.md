

# Los algoritmos normales

Ah, no sé cuál es el siguiente.

## Cómo probar

> Debes probar los siguientes comandos en Linux o Mac, o en el bash de Windows. Además, debes asegurarte de que el sistema operativo que estás utilizando tenga instalados `gcc` y `make`

### Algoritmos

```bash
# Test the algorithms of bubble sort
make test_bubble_sort
```

```bash
# Test the algorithms of selection sort
make test_selection_sort
```

```bash
# Test the algorithms of merge sort
make test_merge_sort
```

```bash
# Test the algorithms of heap sort
make test_heap_sort
```

```bash
# Test the algorithms of quick sort
make test_quick_sort
```

```bash
# Test the algorithms of binary search
make test_bi_search
```
